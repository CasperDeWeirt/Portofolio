Beach Diorama

A diorama of a beach house

Interactive 3D Model

Project Information

Type: 3D Project

Tools: Blender, Photoshop

Duration: 3 months

Team: Solo

My Role: 3D Artist

About the Project

This project was created as an assignment for the course "3D1" at DAE Howest. The goal was to create a diorama of a beach house,learning the skills to make props and buildings and then showcasing my skills in 3D modeling and texturing. This project took 3 months and was completed in the first semester of the course, where it was the exam project.

This was one of my first projects in 3D modeling so i still struggled with a lot, resulting in me barely not passing the course with this project.

My Role

I had to personaly find reference, create man made props and buildings, learn to create vegetation and natural made objects adn put them together in a scene where they make sense. I also had to unwrap, texture and bake every prop.

  • 3D modelling

Development

This project took 3 months, over which i learned the skills. Back then it felt like too little time, but looking back on it now, I messed up a lot and it couldve been done way faster with the proper knowledge. We first had to make 3 simple props, then 2 comple props, which had to contain 1 vehicle. After the props were finished, we had to make our buildings adn then our layout/terrain. Last but not least, I focussed on grass and trees and small details that could lighten up the scene and make it feel more alive.
